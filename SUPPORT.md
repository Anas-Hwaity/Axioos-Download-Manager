# Support

Use the repository's GitHub Issues page for reproducible Axioos Download Manager defects, questions, and feature requests.

For a defect report, include:

- the Axioos version and Windows version;
- the browser and Axioos extension version when browser integration is involved;
- exact steps that reproduce the problem;
- what you expected to happen and what happened instead;
- a sanitized diagnostics export when it is relevant and safe to share.

Do not include passwords, cookies, authorization headers, private tokens, signed download URLs, or other secrets in a public issue.

For security-sensitive problems, follow [SECURITY.md](SECURITY.md) instead of publishing exploit details or private data.

Support claims for Windows, browser integration, and the installer apply only to release artifacts that have passed the corresponding release verification for that version.
